# Версия 0.2.0

Согласовано пользователем: исправить открытие PDF из других программ, уменьшить APK, провести связанный рефакторинг и проверить изменения как вторую версию.

- ACTION_VIEW + application/pdf: приложение доступно в «Открыть с помощью», принимает локальные content/file URI, обрабатывает запуск и новый документ в уже открытой Activity.
- Метаданные и права доступа вынесены из ViewModel в DocumentAccess. Сохранены история и формат DataStore, applicationId и ключ подписи для обновления 0.1.0.
- Вместо библиотеки всех иконок — только используемые vector drawable; release оптимизируется R8 и удалением неиспользуемых ресурсов.
- Обязательные проверки: unit-тесты, debug/release Lint и сборки; Android-тесты регрессии и входящих Intent; проверка оптимизированного release на Android; сравнение размеров, подписи и установки обновления 0.1.0 → 0.2.0.
- Результат: подписанный APK 0.2.0, отчёт с фактическими результатами, изменения в отдельной ветке и локальный коммит после проверок. Отправка ветки в GitHub предусмотрена запросом пользователя; main не перезаписывается.

Ограничения: сторонняя программа должна передать корректный MIME и доступ на чтение. Если предоставлен только временный доступ, повторное открытие из истории после прекращения доступа может потребовать выбрать файл заново. ACTION_SEND для приёма документов и сетевые URL не входят в эту доработку.
