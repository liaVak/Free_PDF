- Добавлен `ReaderUiTest.openJumpZoomAndReopenFromHistory`: открытие тестового PDF через ViewModel, отображение страницы, переход на страницу 3, кнопки масштаба и повторное открытие из истории. Тест скомпилирован, но не выполнен; системный файловый диалог этим сценарием не проверяется.
- `connectedDebugAndroidTest` не дошёл до тестов: в offline-режиме отсутствовали зависимости Android Test Platform; при загрузке из Google Maven произошла ошибка TLS handshake для `com.android.tools.utp:utp-common:31.13.2`. Это ошибка подготовки среды, а не результат теста приложения.
- 29 октября повторно запущен Android 12 / API 31 (`pdf-reader-api31`, x86_64, 1536 МиБ RAM, 2 виртуальных ядра). Ubuntu сама работает под гипервизором; `/dev/kvm` отсутствует, эмулятор использовал `-accel off`.
- ADB подключился, Android дошёл до `system_server`, но `sys.boot_completed=1` за примерно 10 минут получен не был. По просьбе пользователя остановлены ожидание тестов и эмулятор. Установка и запуск приложения в этой попытке не выполнялись.
- Сохранён `scripts/test_emulator.sh` для прямого запуска уже собранного тестового APK через ADB без Gradle UTP. Синтаксис Bash проверен; полный цикл скрипта пока не проверен.
- Всего подготовлено 6 Android-тестов. Ни один не объявляется пройденным или упавшим: результатов исполнения нет.

Журналы сохранены локально в `output/logs/` (исключены из Git): `emulator-validation-build.log`, `emulator-validation-tests-build.log`, `emulator-validation-connected.log`, `emulator-validation-runtime.log`, `emulator-validation-direct.log`, `emulator-system-startup.log` и диагностические журналы Android.

## Ручные сценарии

Установить APK на Android 12+; открыть текстовый PDF и скан, проверить прокрутку/масштабирование/переход, закрытие и повторное открытие, поворот экрана, системную тёмную тему. Проверить внешний вид кириллицы и других нужных шрифтов, особенно если они не встроены. Проверить отправку файла и его открытие получателем. Отдельно проверить большие PDF, смешанные размеры страниц, удалённый файл и повреждённый документ.

Наличие кода функции и теста не означает успешную проверку на устройстве. Точное воспроизведение отсутствующего невстроенного шрифта не гарантируется.
