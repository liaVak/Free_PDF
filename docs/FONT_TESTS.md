# Проверка PDF и шрифтов

Файлы созданы скриптом `scripts/generate_fixtures.py`; исходные документы пользователя не используются.
Лицензии встроенных DejaVu, URW и Noto находятся в `docs/licenses/`.
Эталоны `app/src/androidTest/assets/reference/` получены независимым рендерером Poppler.

| PDF | Назначение | Ожидаемый результат |
| --- | --- | --- |
| embedded.pdf | Подмножества TrueType, полный Type 1 | Кириллица, латиница, лигатуры, математика; обычное, жирное и наклонное начертания |
| full-truetype.pdf | Полностью встроенный DejaVu Sans TrueType | Латиница и цифры без замены гарнитуры |
| scripts-cff.pdf | OpenType/CFF, Noto Arabic и CJK | Соединённое арабское письмо справа налево, китайские, японские и корейские символы |
| fallback.pdf | Невстроенный Helvetica | Читаемая латиница; отличия подстановки допустимы |
| fallback-cyrillic.pdf | Намеренно удалённые программы шрифтов | Диагностический тест кириллицы; точная гарнитура не гарантируется |
| mixed.pdf | Разные размеры и ориентации | Три страницы без изменения пропорций |
| large.pdf | 300 страниц | Ленивая загрузка без хранения всех bitmap |
| scan.pdf | Растровая страница | Тот же вид, что у embedded.pdf, без OCR |

## Обязательный шлюз перед интерфейсом

`./gradlew connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=ru.ilyavakarin.pdfreader.FontRenderingTest`

Тест сравнивает встроенные шрифты с эталонами в обе стороны, допускает погрешность сглаживания в 1 пиксель и требует совпадение не менее 95% тёмных пикселей. Он также проверяет рендеринг при увеличении. Результаты сохраняются в external files приложения для визуальной проверки. Этот порог не заменяет визуальную проверку гарнитур и отдельных символов.

Проверять Android 12 и физический телефон: обычный масштаб, 2× и 4×; отсутствие квадратов, пропавших символов, неверных начертаний и сдвигов текста. Для невстроенных шрифтов документировать реальные ограничения без обещания точного воспроизведения.

## Воспроизведение эталонов

Нужны Python с reportlab/pypdf, системные Cairo/Pango, Poppler, шрифты DejaVu, URW Base35, Noto Core/CJK. Запустить `python3 scripts/generate_fixtures.py`. С помощью `pdffonts` проверить реальные типы шрифтов и признаки emb/sub. Эталоны изменять только после визуальной проверки; не обновлять автоматически при падении Android-теста.
