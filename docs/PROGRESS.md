## Реализовано

- Нативный интерфейс Kotlin + Jetpack Compose, Android 12+, русский язык и системная светлая/тёмная тема.
- Системный выбор PDF, история последних 20 документов, удаление записей без удаления файлов.
- Вертикальная лента, масштаб 1–4× жестом/кнопками, двойное касание 1×/2×, горизонтальное перемещение увеличенной страницы.
- Счётчик страниц, переход по номеру, сохранение и восстановление страницы и относительного смещения.
- Передача исходного PDF через системное меню «Поделиться» с FileProvider и временным разрешением чтения; фоновая подготовка копии и очистка старых копий.
- Изолированный PdfEngine на системном PdfRenderer: фоновая последовательная работа, bitmap-кэш 24 МиБ, предварительная загрузка соседей и отдельный рендеринг увеличенной видимой области.
- Обработка ошибок доступа/формата и повторная загрузка страниц. Исправлена очистка renderer при отмене открытия.
- Unit-тесты истории/позиции и инструментальные тесты рендеринга, истории и пересылки; восемь тестовых PDF с эталонами и лицензиями.
- README, установка среды, Gradle Wrapper и скрипт подписанной release-сборки.

## Среда

Диск VirtualBox увеличен пользователем. По его разрешению /dev/sda2 и ext4 расширены на новый объём: диск около 70 ГиБ, файловая система около 69 ГиБ. Перед изменением таблица разделов сохранена в /root/pdf-reader-sda-before-resize-20261025.sfdisk. Первоначальный недостаток места устранён.

Android Studio Rabbit 1 находится в .tools/android-studio; для Gradle используется локальный JDK 21, для самой IDE — встроенный JDK 25. Установлены API 36, Build Tools 36.0.0, Platform Tools и образ Android 12. Сборки: source scripts/env.sh, затем ./scripts/release.sh.

Эмулятор запускается без аппаратного ускорения: Ubuntu сама находится в виртуальной машине, `/dev/kvm` недоступен. При повторной попытке 29 октября Android дошёл до системных служб, но за примерно 10 минут не завершил загрузку. Эмулятор остановлен по просьбе пользователя. Android-инструментальные проверки не объявляются пройденными. Физический телефон не подключён.

Запуск через Gradle также столкнулся с отсутствующим компонентом UTP и ошибкой TLS при его загрузке. Для будущего запуска без UTP сохранён `bash scripts/test_emulator.sh` (после сборки обоих APK). Все журналы попытки находятся в `output/logs/`; подробности и ограничения — в VALIDATION.md.
