# PDF Reader

> **Версия 0.2.0 проверена на Android 12.** Добавлено открытие PDF из других приложений. Release APK уменьшен с 45,0 до 2,42 МБ; прошли 3 unit-теста, 9 Android-тестов и проверки обновления/release. Фактические результаты — в [отчёте 0.2.0](docs/RELEASE-v0.2.0.md); история проверок — в [docs/VALIDATION.md](docs/VALIDATION.md).

Локальная PDF-читалка для Android 12+ на Kotlin и Jetpack Compose. Интерфейс на русском, без сервера, аккаунтов и разрешения на интернет. Оригиналы документов не изменяются.

## Возможности

Открытие через системный файловый диалог и «Открыть с помощью» из других приложений, вертикальная лента страниц, масштаб 1–4×, переход по номеру, последние 20 документов и восстановление позиции. Кнопка «Поделиться» передаёт исходный PDF через системное меню Android. Шрифты документа отображает PDF-движок, независимо от шрифта интерфейса.

## Среда на этой машине

- Ubuntu 26.10 x86_64; Android Studio Rabbit 1 2026.2.1.8 в `.tools/android-studio`.
- Отдельный Ubuntu OpenJDK 21.0.12.1 для Gradle: встроенный JDK 25 используется самой Android Studio.
- Android SDK API 36, Build Tools 36.0.0; `minSdk=31`, `targetSdk=36`.
- Gradle 8.13 (Wrapper с SHA-256), AGP 8.13.2, Kotlin 2.2.21, Compose BOM 2025.10.01.
- Git локальный; имя `ilya.vakarin`, технический email `ilya.vakarin@users.local`.

Инструменты находятся в игнорируемой `.tools`. Полная установка с эмулятором и сборочными кэшами требует приблизительно 12 ГБ свободного диска. Сетевой доступ нужен для установки и первой сборки.

```bash
python3 scripts/install_tools.py
python3 scripts/install_jdk.py
source scripts/env.sh
./scripts/install_sdk.sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Установщик JDK использует закреплённые пакеты Ubuntu 26.10. На другой ОС установите совместимый JDK 21 и настройте `JAVA_HOME` самостоятельно. Kotlin компилируется в JVM 17.

Откройте корень проекта в `.tools/android-studio/bin/studio`. В настройках Gradle выберите JDK из `.tools/jdk`. Пути SDK находятся в игнорируемом `local.properties`. Для сборки из терминала сначала выполняйте `source scripts/env.sh`. Системная установка Gradle не требуется.

## Запуск и проверки

На телефоне включите режим разработчика и USB-отладку, подключите USB и подтвердите доступ. `adb devices` должен показать статус `device`. При отсутствии прав установите udev-правила Android средствами ОС.

```bash
source scripts/env.sh
adb devices
./gradlew installDebug
./gradlew connectedDebugAndroidTest
```

Для Android 12 есть `./scripts/start_emulator.sh -no-window`. AVD создаётся в `.tools/avd` и сохраняется между перезагрузками. Для быстрых проверок необходим доступный KVM. Без него загрузка может не завершиться за разумное время; используйте физическое устройство или среду с ускорением. Образ AOSP не содержит мессенджеров: проверка реальной пересылки в два приложения выполняется на телефоне.

Если Gradle не может загрузить Android Test Platform, подготовлен прямой запуск тестов через ADB:

```bash
source scripts/env.sh
./gradlew assembleDebug assembleDebugAndroidTest
bash scripts/test_emulator.sh
```

Скрипт ожидает загрузки локального эмулятора, устанавливает оба debug APK и запускает инструментальные тесты. Последний прогон 30 октября на Android 12 с KVM: 9 тестов прошли за 18,620 с; журналы сохраняются в `output/logs/`.

Шрифты, лицензии, эталоны и порядок визуальной проверки описаны в [docs/FONT_TESTS.md](docs/FONT_TESTS.md). Состояние проведённых проверок фиксируется в [docs/VALIDATION.md](docs/VALIDATION.md).

## APK и подпись

```bash
./scripts/release.sh
```

Результат: `output/apk/pdf-reader-0.2.0.apk` и SHA-256. При первом запуске скрипт создаёт локальный ключ и случайные пароли в `.secrets`, исключённой из Git. Скрипт не печатает пароли. Сохраните `.secrets` на отдельном носителе: для обновления установленного приложения нужен тот же ключ. Скрипт не выполняет внешнее резервное копирование.

Установка: `adb install -r output/apk/pdf-reader-0.2.0.apk` либо передайте APK на телефон и разрешите установку из выбранного источника.

## Архитектура и данные

Один модуль `app`: `MainActivity` принимает входящие Intent через `PdfIntents`, `DocumentAccess` управляет метаданными и URI-разрешениями. `PdfEngine` изолирует системный `PdfRenderer`, ViewModel управляет документом, DataStore хранит URI и позицию. Рендеринг выполняется последовательно в фоне, bitmap-кэш ограничен 24 МиБ. Большие изображения ограничиваются по размерам; увеличенная видимая область рендерится отдельно.

Приложение сохраняет разрешение на выбранный URI. Перемещение или удаление файла, отзыв разрешения или ограничения провайдера могут потребовать выбрать документ заново. Удаление из истории не удаляет исходный файл. Перед отправкой создаётся приватная копия; копии старше 24 часов очищаются при следующем запуске.

Встроенные шрифты и их подмножества использует рендерер. Для невстроенных шрифтов применяется его подстановка, зависящая от Android и доступных системных шрифтов. Точная гарнитура в этом случае не гарантируется. Повреждённые и защищённые паролем PDF могут не открываться. Поиск, OCR, аннотации и установка собственных шрифтов не входят в версию 0.2.
