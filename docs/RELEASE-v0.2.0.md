# PDF Reader 0.2.0

## Изменения

- Читалка зарегистрирована для ACTION_VIEW / application/pdf и появляется в «Открыть с помощью» для локальных content/file URI. При повторном открытии документ меняется в существующей Activity; пересоздание экрана не возвращает старый Intent и не открывает закрытый файл заново.
- Работа с именами документов и разрешениями вынесена в DocumentAccess. Для file URI имя берётся из пути; необязательные метаданные провайдера имеют резервное значение. Формат истории и applicationId сохранены.
- Библиотека material-icons-extended удалена. Используются девять небольших vector drawable. Release включает R8, оптимизацию и удаление неиспользуемых ресурсов; глобальные keep-правила не добавлены.
- Версия повышена до 0.2.0 (versionCode 2). Для обновления используется прежний ключ подписи.
- Скрипт выпуска определяет имя APK по метаданным сборки; скрипт Android-тестов не принимает нулевое число тестов за успех и сохраняет журналы. Mapping R8 архивируется рядом с APK для расшифровки будущих стеков ошибок.

Настройка R8 соответствует [документации Android](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization). Регистрация входящих файлов основана на [механизме Intent filters](https://developer.android.com/guide/components/intents-filters).

## Повторение проверок

```bash
source scripts/env.sh
./scripts/release.sh
bash scripts/test_emulator.sh emulator-5554
# Следующие проверки — только на отдельном тестовом эмуляторе.
# После debug-прогона удалить тестовую установку (её данные будут удалены),
# сохранив установленный тестовый APK с внешним отправителем:
adb -s emulator-5554 uninstall ru.ilyavakarin.pdfreader
python3 scripts/smoke_release.py --serial emulator-5554 \
  --upgrade-from output/apk/pdf-reader-0.1.0.apk \
  --apk output/apk/pdf-reader-0.2.0.apk
```

Устанавливать разные варианты с несовместимыми подписями в один пакет нельзя. Используйте отдельный тестовый эмулятор; удаление установленного приложения удаляет его данные. Для проверки пользовательского обновления устанавливайте новый release поверх старого через `adb install -r`, с тем же ключом.

## Ограничения

- Отправитель должен передать MIME application/pdf (либо content provider должен сообщить его Android) и разрешение на чтение. Сетевые ссылки не обрабатываются.
- Временный URI-grant от сторонней программы может закончиться; тогда для повторного открытия из истории нужно выбрать документ заново. Исходный файл не копируется в постоянную библиотеку приложения.
- Эта версия добавляет открытие через ACTION_VIEW. Входящий ACTION_SEND не зарегистрирован. Исходящая кнопка «Поделиться» сохранена.
- Новый прогон на Android не подтверждает работу каждого стороннего файлового менеджера и телефона. Изменение APK-размера само по себе не является измерением скорости интерфейса.
