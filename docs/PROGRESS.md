## Среда и препятствие

- Ubuntu 26.10 работает внутри VirtualBox (модель VBOX HARDDISK).
- Сам диск /dev/sda виден как 26843545600 байт (25 ГиБ), раздел /dev/sda2 ext4 занимает почти весь диск.
- На момент остановки свободно около 1,6 ГиБ; диск на 70 ГБ в гостевой системе не виден.
- Android Studio установлена в .tools/android-studio (~3,6 ГБ); использует встроенный JDK 25.
- Сборки настроены на отдельный локальный Ubuntu JDK 21 (~289 МБ) через source scripts/env.sh. JDK 25 не подходит выбранному Gradle.
- API 36, Build Tools 36.0.0, Platform Tools установлены. Кэш Gradle занимает ~1,3 ГБ.
- Эмулятор восстановлен из официального архива. Образ Android 12 НЕ восстановлен: распакованный system.img требует ~4,3 ГБ; попытка исчерпала диск. Неполные *.img удалены, прочая папка образа и package.xml могут ошибочно указывать установленный пакет.
- Архив образа /tmp/pdf-reader-package-1.zip (~627 МиБ) проверен SHA-1 по метаданным Google; находится во временной памяти и исчезнет после перезагрузки. Повторная загрузка возможна через scripts/repair_emulator.py.
- .tools/android-sdk/.sdk/arch — ссылка на временный /tmp/pdf-reader-sdk-archives. Перед дальнейшей установкой проверить цель ссылки.
- После заполнения диска индекс Gradle journal-1 был повреждён. Один раз пересоздан, но повторное заполнение диска могло снова повредить кэши. Последняя сборка остановлена через ./gradlew --stop.
- Физический телефон по adb не подключён. /dev/kvm отсутствует. Эмулятор не запускался успешно.
- sudo требует интерактивный пароль. Никаких изменений таблицы разделов или размера диска не выполнялось.

## Как продолжить

1. На хосте VirtualBox проверить, какой виртуальный диск подключён к этой VM, и увеличить его ёмкость. Изнутри гостевой системы расширить виртуальный носитель нельзя. После этого проверить lsblk; только когда /dev/sda станет больше, расширять раздел и ext4. Не выполнять команды изменения разделов без повторной проверки и разрешения пользователя.
2. Обеспечить достаточно свободного места (желательно ещё 8–10 ГБ), восстановить образ Android 12, проверить запуск эмулятора либо подключить телефон.
3. source scripts/env.sh; проверить java -version и adb devices. Остановить Gradle и пересоздать только повреждённый служебный кэш, если ошибка повторяется. Запустить assembleDebug и assembleDebugAndroidTest, исправить ошибки компиляции.
4. Запустить FontRenderingTest на Android 12, просмотреть сохранённые изображения, отдельно проверить fallback-cyrillic. При ошибках встроенных шрифтов не интегрировать движок до устранения проблемы.
5. Завершить UI: выбор PDF, история, вертикальная лента, переход, масштабирование 1–4× с рендерингом видимой области, отправка, жизненный цикл и ошибки. Проверить отмену открытия на предмет утечек renderer при возврате из withContext.
6. Выполнить unit-тесты, инструментальные тесты, lint и визуальные проверки; проверить поворот/процесс/300 страниц/смешанные размеры/отказ доступа/две реальные цели отправки.
7. Только после проверки запускать release.sh, сохранять ключ подписи отдельно, собирать APK. Не ставить v0.1.0 до готовности.
